# Sentinel Client (Minecraft 26.3 Fabric)

Sentinel Client is a client-side anti-cheat testing and telemetry mod for **Minecraft 26.3** using **Fabric** and **Java 21**.

## Installation

1. Install **Fabric Loader** for **Minecraft 26.3** and place the **Fabric API** JAR into your `.minecraft/mods/` folder.
2. Copy `sentinel-client-1.0.0.jar` into `.minecraft/mods/`.
3. Launch Minecraft 26.3 with the Fabric profile.
4. Press **`0`** (zero key, outside of chat/screens) to open the **Sentinel Client** GUI.

## Building from Source

```bash
./gradlew build
```

Built JARs are output to `build/libs/`.
